# Vibefer2

Vibefer2 is an NVIDIA GPU implementation of the proof-producing generalized Fermat number search, derived from Johannes David's Vibefer and Yves Gallot's Genefer. This repository accompanies a study of GPU-specific arithmetic, CUDA graph reuse and scheduling across a heterogeneous four-GPU workstation.

The production search reported the 1,142,232-digit prime `518246744^131072 + 1`. [PrimePages entry 142659](https://t5k.org/primes/page.php?id=142659) records the number and credits the discovery team. The registry and the software provenance are separate records.
